# Claude Certified Developer Course

This section contains notes from Sagar Poudel's Claude Certified Developer course. The notes follow ASD-STE100 Simplified Technical English.

## Why this matters

Staff engineers who build with Claude need to understand how the model works. This knowledge helps you make good decisions about model choice, prompting, and API patterns. The Foundations module gives you the concepts you need before you write code.

## Course structure

The course has multiple modules. This section covers the **Foundations** module only.

### Foundations module

The Foundations module has five topic groups:

1. **How LLMs behave** — Tokens, the context window, sampling, and non-determinism
2. **Model options and reasoning modes** — The Claude model family and when to use reasoning
3. **Prompting modes** — Zero-shot, one-shot, and multi-shot prompting
4. **Technical substrate** — SDK versus REST, synchronous versus streaming, and async patterns
5. **Recap** — Five key takeaways
